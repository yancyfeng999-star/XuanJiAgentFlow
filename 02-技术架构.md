│  └─────┬──────┘  └───────┬────────┘   │
│        └────────┬────────┘            │
│         ┌───────▼───────┐             │
│         │    调度器      │             │
│         │ DAG解析+状态机 │             │
│         └──┬────┬───┬───┘             │

## 进程模型

```
Tauri App (主进程)
  ├── Frontend 进程 (端口 3000, 静态文件)
  ├── Backend 进程 (端口 8000, FastAPI)
  │     ├── 规划器模块
  │     ├── 编排器模块
  │     ├── 调度器模块
  │     ├── 执行器模块
  │     ├── 导出器模块
  │     ├── 监视器模块
  │     ├── 收集器模块
  │     └── 存储器模块
  └── Hermes 进程 (端口 8001, 外部可选)
```

## 模块间通信

```
Frontend ◄──WebSocket──► Backend ◄──HTTP──► Hermes
(3000)                    (8000)              (8001)

Backend 内部模块间：Python函数调用（同进程）
Backend → LLM API：HTTP（规划器调用OpenAI/Claude）
```

所有端口仅绑定 localhost。

## 通信协议

### REST API

```
# 输入
POST   /api/input                     # 提交选题

# 规划
POST   /api/plan                      # AI规划任务DAG
POST   /api/plan/replan               # 重新规划
POST   /api/plan/replan局部           # 局部重规划

# 编排
GET    /api/runs/:id/graph            # 获取DAG
PUT    /api/runs/:id/graph            # 更新DAG（编辑后）
POST   /api/runs/:id/confirm          # 确认DAG

# 调度
POST   /api/runs/:id/start            # 开始执行
POST   /api/runs/:id/pause            # 暂停
POST   /api/runs/:id/resume           # 恢复
POST   /api/runs/:id/cancel           # 取消

# 任务
GET    /api/runs/:id/tasks            # 获取所有节点
PUT    /api/runs/:id/tasks/:tid       # 更新节点
POST   /api/runs/:id/tasks/:tid/retry # 重试
POST   /api/runs/:id/tasks/:tid/skip  # 跳过

# 导出
POST   /api/runs/:id/export           # 导出prompt文本

# 收集
POST   /api/runs/:id/tasks/:tid/result # 提交手动执行结果
GET    /api/runs/:id/results          # 汇总所有结果

# 状态
GET    /api/status                    # 系统状态
GET    /api/runs                      # 历史运行列表
```

### WebSocket

```
ws://localhost:8000/ws/runs/:id

# 服务端推送
task_started       # 任务开始
task_progress      # 进度更新
task_log           # 日志流
task_output        # 产出更新
task_completed     # 任务完成
task_failed        # 任务失败
run_completed      # 整个运行完成
run_failed         # 整个运行失败
```

## 数据模型

### SQLite 表

```sql
-- 运行记录
CREATE TABLE runs (
    id TEXT PRIMARY KEY,
    goal TEXT NOT NULL,
    task_graph JSON NOT NULL,
    status TEXT DEFAULT 'draft',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    started_at DATETIME,
    completed_at DATETIME,
    config JSON
);

-- 任务节点
CREATE TABLE tasks (
    id TEXT PRIMARY KEY,
    run_id TEXT NOT NULL,
    title TEXT NOT NULL,
    description TEXT,
    agent_type TEXT NOT NULL,
    status TEXT DEFAULT 'pending',
    dependencies JSON DEFAULT '[]',
    result JSON,
    logs JSON DEFAULT '[]',
    output_files JSON DEFAULT '[]',
    started_at DATETIME,
    completed_at DATETIME,
    retry_count INTEGER DEFAULT 0,
    max_retries INTEGER DEFAULT 3,
    FOREIGN KEY (run_id) REFERENCES runs(id)
);

-- 系统配置
CREATE TABLE config (
    key TEXT PRIMARY KEY,
    value JSON NOT NULL,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 技术栈

| 层 | 技术 | 理由 |
|----|------|------|
| 桌面壳 | Tauri 2.x | 轻量、原生性能 |
| 前端 | React 18 + TypeScript | 生态成熟，ReactFlow集成 |
| DAG编辑器 | ReactFlow | 专业节点图编辑库 |
| UI组件 | shadcn/ui | 现代、可定制 |
| 后端 | Python FastAPI | 异步高性能 |
| 规划器 | LLM API (OpenAI/Claude) | 直接调用，不依赖引擎 |
| 调度器 | Python DAG解析 + 状态机 | 自研核心 |
| 数据库 | SQLite | 轻量、无需额外服务 |
| 通信 | WebSocket + REST | 实时+标准API |
